# Network Intrusion Detection System (NIDS)

## Project Overview
The Network Intrusion Detection System (NIDS) is a Python-based project designed to demonstrate the detection of suspicious network activity.

## Objectives
- Identify suspicious network activity.
- Display alerts for suspicious events.
- Record detected alerts in a log file.
- Demonstrate basic network security concepts.

## Technologies Used
- Python
- Snort Rules Format

## Project Files
- nids_monitor.py - Main Python program.
- local.rules - Basic network detection rule.
- alerts.log - Log file generated when suspicious activity is detected.

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Run the following command:

   python nids_monitor.py

## Features
- Displays source IP address.
- Displays destination IP address.
- Shows protocol information.
- Detects suspicious status in test data.
- Generates alerts for suspicious activity.
- Saves alerts to a log file.

## Note
This project is an educational demonstration using sample data. It does not monitor live network traffic.
